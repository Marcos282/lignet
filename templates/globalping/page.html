{% if kind == 'traceroute' %}Como interpretar o traceroute online?{% elif kind == 'dns' %}Como verificar propagação DNS?{% elif kind == 'http' %}Como verificar a disponibilidade de sites?{% else %}O que um ping mundial mostra?{% endif %}

{% if kind == 'traceroute' %}

Cada salto representa uma etapa da rota observada a partir de uma sonda. Compare as tabelas por localidade para encontrar caminhos diferentes. Um salto sem resposta não comprova falha: roteadores podem filtrar ou limitar mensagens de diagnóstico.

As coordenadas do mapa são das sondas, não de cada roteador. Não estimamos localização dos saltos ou do destino.

{% elif kind == 'dns' %}

O teste DNS mundial consulta A, AAAA, MX, NS, TXT ou CNAME a partir das regiões escolhidas. As respostas exibem registros, TTL e servidor DNS quando retornado pela API.

Comparamos conjuntos de registros e códigos DNS, desconsiderando a ordem e o TTL. Diferenças podem decorrer de cache, balanceamento ou DNS geográfico; elas não comprovam falha nem propagação incompleta. Uma amostra igual não representa todos os resolvers da internet.

{% elif kind == 'http' %}

O teste HTTP consulta o site com HEAD e mostra o status e os tempos informados pela Globalping: DNS, conexão TCP, TLS, primeiro byte, download e total.

Uma resposta 3xx mostra o redirecionamento informado no cabeçalho Location. A interface mostra somente os dados retornados pela API, sem reconstruir uma cadeia de redirecionamentos. Alguns sites bloqueiam HEAD; isso não comprova indisponibilidade para navegadores.

{% else %}

O ping online mede o tempo de ida e volta dos pacotes entre uma sonda e o destino. As latências mínima, média e máxima, em milissegundos, ajudam a comparar a conectividade internacional. A perda de pacotes aparece somente quando retornada pela medição.

Distância, operadora, rota e filtragem ICMP influenciam o resultado. Um ping sem resposta não prova que o site está fora do ar. Use também o teste HTTP para verificar o serviço web.

{% endif %}
